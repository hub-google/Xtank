# 09｜名詞表與 FAQ

這份文件給第一次接觸 X-TANK 的讀者快速查詢。

## 名詞表

### X-TANK ONLINE
VisualLand 開發的 3D 即時多人坦克射擊遊戲，台灣由因思銳代理。

### X-TANK
既是遊戲名稱的一部分，也是八種原始坦克之一。X-TANK 車種本身屬於能力平均、適合入門的類型。

### Deathmatch
個人競賽模式。至少 2 人、最多 8 人，依房主設定累積勝利條件。

### Team Death Match
團隊競賽模式。玩家分隊作戰並累積團隊勝利積分。

### Capture the Flag / CTF
拔旗模式。重點是取得並持有場上的 X-TANK 軍旗以得分；單純擊毀敵車不直接給勝利點。

### Speed
坦克移動速度相關能力。

### Attack
攻擊能力。

### Defense
防禦能力。

### Energy
能源／耐久相關能力。精確公式目前尚未完整考證。

### Collision
撞擊破壞能力。M-TANK 特別擅長這一項。

### Main Server / Dungeon Server
Xen Archives 保存地圖資料時使用的集合／伺服器標示，不應直接當成單張地圖名稱。

## FAQ

### Q1：X-TANK 是單機還是網路遊戲？

核心定位是網路多人對戰遊戲。當年資料描述房間式戰場、最多 8 台坦克同場，並可開設密碼戰場。

### Q2：它是純射擊遊戲嗎？

不是。它有即時射擊操作，也有經驗、金錢、等級／官階、能力成長、購買武器與道具等 RPG 式長期成長元素。

### Q3：最多幾個人一起玩？

目前資料可確認每場最多 8 台坦克。

### Q4：原版有幾種坦克？

八種：A-TANK、D-TANK、H-TANK、M-TANK、O-TANK、R-TANK、S-TANK、X-TANK。

### Q5：第一次玩應該選哪台？

建議先用 X-TANK。它能力平均、容易理解，適合先熟悉移動、瞄準、武器切換與模式規則。

### Q6：哪台最快？

目前資料把 R-TANK 描述成追求極高速度的坦克；H-TANK 也屬高速車。若要做精確速度排行，仍需要完整原始數值表。

### Q7：哪台最硬？

D-TANK 的已知特色是火力與裝甲突出。若要精確比較所有車的 Defense 數值，仍需要完整數據。

### Q8：哪台可以撞人？

所有坦克都有 Collision 成長概念，但 M-TANK 的撞擊破壞力特別突出，因此最容易被理解成近戰／撞擊型。

### Q9：A-TANK 有什麼特別？

它有雷達能力，可以掌握敵方位置，這是八台車中相當有辨識度的情報能力。

### Q10：H-TANK 有什麼特殊抗性？

已知資料記錄它受到雷射與電漿類攻擊時可降低 50% 傷害。

### Q11：有幾種武器？

當年資料宣稱測試版有近 120 種武裝配備，但目前還沒有可靠的完整名稱與數值清單。

### Q12：目前知道哪些武器？

至少能確認飛彈、Howitzer、Gun、Laser、Plasma 等類別，以及颶風飛彈、硝基甲烷彈、Plasma Cannon 等名稱。

### Q13：真的有 50 張地圖嗎？

不能這樣直接下結論。當年文字是「50 種不同戰場的背景」，沒有證明這等於 50 張各自具有正式名稱的獨立地圖。

### Q14：有哪些場景？

目前可確認曾出現桌面、棋盤、電腦電路板、巴黎香榭麗舍大道、沙漠、古希臘宮殿、英國巨石陣、阿富汗戰場等場景主題。

### Q15：拔旗模式是不是殺越多人越容易贏？

不一定。該模式可確認「擊毀敵車本身不直接給勝利點」，真正的得分核心是持有旗幟一段時間。

### Q16：怎麼操作？

最基本是：WASD 移動、滑鼠瞄準、左鍵／Ctrl 射擊、1–7 換武器、F1–F7 換道具、右鍵／Space 用道具、C 切換五種視角。

### Q17：為什麼 repo 裡很多地方寫「尚待考證」？

因為這是一款 2000 年代初期的網路遊戲，官網與完整資料大多已失效。這個 repo 的原則是寧可清楚標記未知，也不把玩家記憶、場景描述或推測寫成官方事實。

### Q18：如果想真正完整還原遊戲，下一步是什麼？

最有價值的是找到原始客戶端／安裝檔，解包資源與字串，再建立完整的坦克數值、武器道具、商店、地圖與版本對照表。
