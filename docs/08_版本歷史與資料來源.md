# 08｜版本歷史與資料來源

本 repo 的主要研究範圍是約 **2000–2002 年**的 VisualLand《X-TANK ONLINE》。較晚版本只在能幫助理解地圖／版本沿革時作補充。

## 已知時間線

- **2001-02-25｜v1.22**：Xen Archives 保存早期 Main Server 地圖索引。
- **2001-07｜台灣開放測試**：中文前瞻資料記錄台灣測試資訊。
- **2001-08-05｜v1.32**：Xen Archives 保存 Dungeon Server 地圖索引。
- **2001 年下半年｜阿富汗主題宣傳／更新**：中文報導記錄「決戰阿富汗／決戰賓拉登」題材。
- **2002-02｜中文前瞻／試玩資料**：可確認 8 台坦克、近 120 種配備、50 種戰場背景、多人模式與成長系統等描述。
- **2002-03-12｜新浪試玩頁**：列出遊戲基本配備需求、操作鍵位、8 人對戰與三種模式。
- **2002-05-18｜v1.49b**：Xen Archives 保存 Main Server 與 Dungeon Server 地圖索引。
- **2004-05-03｜v1.70**：Xen Archives 有 Main Server、Dungeon Server、Christmas 集合；超出主要研究範圍。

## 主要來源

- 8 台性能不同的坦克

- 操作鍵位

## 可信度分級

為了避免「記憶中的 X-TANK」和「有史料支持的 X-TANK」混在一起，本 repo 採以下原則：

### A｜可直接確認

來源文字直接寫出，例如：

- 最多 8 人
- `WASD` 操作
- 三種模式
- 八台坦克名稱
- v1.49b 日期

### B｜可合理整理，但不是官方用詞

例如：

- 把 D-TANK 稱為「重型坦克」
- 把 A-TANK 稱為「偵察／情報型」
- 說 R-TANK 適合用速度避免正面換血

這些是為了幫讀者理解而做的分類或策略推導。

### C｜目前不能確認

例如：

- 50 種背景是否等於 50 張獨立地圖
- 每一張地圖的正式名稱
- 近 120 種裝備的完整名稱／數值
- 完整商店價格
- Energy 的精確公式

這些項目不應靠猜測補齊。

## 目前最重要的研究缺口

若要把這個 repo 進一步做成接近「X-TANK 百科」，優先順序應是：

1. 找到可執行的原始安裝檔／客戶端。
2. 解包資源與字串表。
3. 還原完整武器、道具與價格資料。
4. 對應地圖檔名、遊戲內顯示名與版本。
5. 找到完整 UI／商店／能力值畫面截圖。
6. 確認各坦克的完整原始數值與成長公式。

## 編輯守則

新增資料時請盡量保留：

- 原始來源網址
- 日期
- 原文名稱
- 「已確認／推導／未知」狀態

這樣後續即使找到更完整的客戶端，也能快速修正，而不會不知道哪些內容原本只是推測。
