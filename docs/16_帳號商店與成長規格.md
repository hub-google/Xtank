# 16｜帳號、RPG 成長、商店、配裝與公平性 v0.1

## 已知史實與不足
當年 X-TANK 具有帳號、階級、經驗／獎金與戰前購物。近 120 種武裝配備是一項宣傳總量。未找到可核對的完整價目表、掉落率、升級公式。韓文玩家回顧提到後期強力升級引起新手與老手落差，故本復刻把經典與公平模式分離。

## P：體驗與資料欄位
- 訪客 → 設定暱稱 → 選車 → 配裝 → 找房／建房 → 對戰 → 戰果 → 商店／升級 → 再戰；可在訪客模式立即進房。
- 玩家資料：playerId、displayName、accountType、createdAt、lastSeenAt、xp、level、currency、rating、tankProgress、inventory、loadouts、settings。
- Inventory 物件：instanceId、itemId、quantity、durability(如有)、obtainedAt、sourceTxnId。禁止直接用本地 localStorage 作為貨幣真相。
- 商店：itemId、價錢、限定級別（若有）、每次購買數量、物品類型、是否可在競技房使用；購物不直接改變已開局狀態。

## P：起始經濟提案
- 訪客初始 1,000 遊戲幣、所有坦克可自由試用；常用基礎武器免費且不耗彈藥。
- 一場正常完成比賽固定 60 經驗與 80 幣；勝利 +20 經驗與 +40 幣；優秀目標表現最多 +20。以上需設每日防濫用上限。
- LevelXP(n) = 100 × n × (n+1) / 2（從等級 1 到等級 n+1 的累積閾值候選）；不得呈現為原版公式。
- 武器購買價格初版：Chemical 150、Ion Missile 200、Mine 100；其餘首版用免費或訓練配裝，避免未完成系統擋住對戰。
- 成長點 5 個屬性：Speed／Attack／Defense／Energy／Collision；歷史精確意義待驗；公平賽模式同化同級數值避免新手被壓制。

## P：存取與交易安全
- matchResult 必須由權威伺服器產出，寫入 ledger 時用 matchId+playerId 唯一鍵實現 exactly-once 效果。
- 任一購買以 transactionId 和 playerId 綁定，扣幣與新增道具在同一 DB transaction；庫存不可為負，數量與價格以伺服器定價。
- 發現重試、斷線、雙擊購買需回傳原結果；避免重複扣款、重複獲幣。
- 禁止無限對刷：同組玩家重複短時交戰不獲得重複高額獎勵；保留審計紀錄和人工封禁程序。
- 玩家可刪帳號、匯出個人資料（P1 之後），保留期限與隱私告知在公開測試前確立。

## P：房間公平選項
- CASUAL_CLASSIC：永久配裝與成長生效，明顯標示。
- COMPETITIVE_NORMALIZED：所有玩家同等成長點數與公平裝備預算；技能可用但由標準化配置決定。
- PRACTICE：不發幣、不刷經驗、可打 AI。
- 任何增加戰力的現金付費功能均不做；若日後考慮商業化先評估權利與法遵。

## 驗收
同局重送結果 100 次只入帳 1 次；購買重送 100 次只扣一次；負幣不可能成功；不同頁籤嘗試同時購買不會多出免費物品；匿名登入可直接測試。
