# 01｜核心玩法與操作

X-TANK 的操作邏輯接近早期 PC 第三人稱射擊遊戲：**鍵盤控制坦克移動，滑鼠控制視線與射擊方向**。

## 基本操作表

| 功能 | 按鍵 |
|---|---|
| 前進 | `W` |
| 後退 | `S` |
| 向左移動 | `A` |
| 向右移動 | `D` |
| 視線／瞄準 | 滑鼠移動 |
| 發射武器 | 滑鼠左鍵或 `Ctrl` |
| 切換武器 | `1–7` |
| 切換道具 | `F1–F7` |
| 使用道具 | 滑鼠右鍵或 `Space` |
| 切換視角 | `C`，共 5 種 |
| 模式／離開相關選單 | `Esc` |

## 操作上真正重要的是什麼？

### 移動與瞄準是分開的

你不是只靠方向鍵「朝敵人走過去」。鍵盤負責位移，滑鼠負責視線與火力方向，因此戰鬥的基本功是：

- 坦克持續移動
- 同時用滑鼠把火力留在敵人身上
- 需要時快速用 `1–7` 切換適合的武器

這也是為什麼不同速度、裝甲與武器特性的坦克會產生明顯不同的玩法。

## 五種視角

保存的操作資料可確認 `C` 能切換五種遊戲視角，但目前來源沒有完整列出每一種視角的官方名稱與相機距離。

對新手來說，可以把它理解成「依戰況切換觀察方式」：

- 近距離交戰時，重視準星與車體方向
- 高速移動時，重視周遭環境
- 找旗或判斷地形時，重視視野範圍

> 以上是操作用途整理，不代表官方對五種視角的正式分類。

## 武器與道具是兩套快捷欄

X-TANK 將兩者分開：

- 數字 `1–7`：武器
- `F1–F7`：道具

因此你可以把戰鬥理解成兩層決策：

1. **我現在用哪種火力？**
2. **我現在需要使用哪個輔助道具？**

當年資料也提到團隊模式的購物內容包含可支援全隊的道具，表示道具並不只服務個人輸出。

## 一次典型交戰流程

以下是依已知操作整理的新手示意：

1. 用移動保持距離或接近對手。
2. 滑鼠轉向，把瞄準方向帶到敵車。
3. 以左鍵／Ctrl 開火。
4. 根據距離或目標狀態切換武器。
5. 需要時切到道具並使用。
6. 若你的坦克擅長撞擊，可進一步利用 Collision 優勢；若是高速或遠距車，則反過來保持空間。

## 常見新手錯誤

- 只會往前開，不會邊移動邊瞄準。
- 忘記武器與道具有不同快捷鍵。
- 在 Capture the Flag 中只顧擊殺，忽略旗幟計分。
- 選了速度極快但裝甲薄的坦克，卻用重型坦克的方式正面換血。
- 不切視角，導致高速移動時失去環境判斷。
