## 本次核查後**沒有**列為現行 BUG 的項目

- `xtank.shop_offers` 資料庫查得 9 項上架商品，**0 項**設定 `stock_limit`。雖然舊 `buy_offer` 有 `STOCK_LIMIT_NOT_IMPLEMENTED` 分支，但它沒有影響現在的上架商品，因此本次不列為目前發生的缺陷。
- `src/simulation.js` 的 `this.tick` 其實每次增加的是 `dt` 秒，不是 `+1` 的整數 tick；其護盾六秒恢復判斷不能誤報成「六個 frame 就開始恢復」。
- Supabase Security Advisor 報告的 `xtank` 私有表「RLS enabled without policy」符合目前只允許後端受信任函式存取資料表的設計；並非應該直接把私人資料表加上一般公開 SELECT policy。
- 共用 Supabase 專案的其他 `public.*` 應用有安全顧問提示，但**不屬於 X-TANK 命名空間**；本次沒有擅自修改其他遊戲／服務的資料表與 API。
- 24 小時公網 WSS 尚未部署是外部交付依賴，不是現行程式執行時的新 BUG；也不把已排除的 MMR 跨服配對／全套原版素材／回放功能列入待修清單。

## 實際修正狀態

八項修正已推至 GitHub `main`。本次沒有改動 Supabase schema 或費用設定；只查詢資料庫結構、實際商品設定及安全顧問摘要。**仍需實際執行驗收才能確認沒有其他運作中的錯誤；不得宣稱「全專案已無 BUG」**。先前被使用者暫停的 EXE 打包、測試與正式部署，本次均未執行。
