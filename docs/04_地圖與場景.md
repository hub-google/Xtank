# 04｜地圖與場景

X-TANK 的地圖資料是目前最容易被誤寫的部分：當年資料確實提到大量戰場背景，也有保存站留下不同版本的地圖集合，但**目前沒有找到一份可靠的官方逐張地圖名稱清單**。

因此本文件刻意把「版本地圖集合」「可確認場景主題」「正式地圖名」分開。

## 當年宣傳怎麼描述？

中文前瞻／試玩資料曾宣稱遊戲具有**50 種不同戰場的背景**。

這句話可以確認「場景變化很多」，但不能直接推論成「官方有 50 張各自具正式名稱的獨立地圖」。來源沒有說清楚這 50 種究竟是：

- 獨立地圖
- 同一地圖的背景變體
- 場景組合
- 或上述內容的混合

所以本 repo 不把「50 種背景」寫成「50 張已確認地圖」。

## 阿富汗主題要特別注意

台灣當年曾以**「X坦克 ONLINE～決戰阿富汗／決戰賓拉登」**等宣傳標題推廣更新內容。

目前能確認的是「這是版本／活動宣傳題材」，不能直接把這串標題當成某一張地圖的遊戲內正式名稱。

## Xen Archives 保存的版本地圖集合

目前找到的 Xen Archives 以版本分組保存地圖連結。

| 版本 | 日期 | 可確認的集合 |
|---|---:|---|
| v1.22 | 2001-02-25 | Main Server |
| v1.32 | 2001-08-05 | Dungeon Server |
| v1.49b | 2002-05-18 | Main Server、Dungeon Server |
| v1.70 | 2004-05-03 | Main Server、Dungeon Server、Christmas |

v1.70 超出本 repo 主要研究的 2000–2002 範圍，但保留作為後續版本索引。

## Main Server / Dungeon Server 是地圖名嗎？

不是。目前應把它們理解為**保存站對地圖集合／伺服器類別的標示**，而不是已確認的單張地圖正式名稱。

同理，`Christmas` 在 v1.70 索引中是一個可確認的集合標示，但目前不應自行延伸成完整單張地圖名清單。

## 地圖會怎麼影響玩法？

以下屬於依已知遊戲機制做的理解整理：

- **開闊地形**：高速／遠距型坦克更容易利用距離。
- **障礙物多的地形**：轉角、遮蔽物與近身接戰會更重要。
- **Capture the Flag**：地圖動線、旗幟位置與撤離路線，比單純找人擊殺更重要。
- **A-TANK 雷達**：在視線被地形阻擋時，情報能力理論上更有價值。

這些是自然戰術推導，不代表已找到當年官方逐圖攻略。

## 為什麼現在不列完整地圖名？

因為要負責任地重建，需要至少取得其中之一：

- 原始地圖檔
- 遊戲內選單截圖
- 安裝檔中的字串／資源
- 當年官網逐圖介紹
- 保存站能對應檔名與遊戲顯示名稱的資料

在沒有這些證據前，本 repo 寧可留下「未知」，也不把場景描述自行命名成官方地圖。
