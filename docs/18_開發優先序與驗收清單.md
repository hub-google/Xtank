## 核心測試矩陣
| 測試 | 操作 | 必須結果 |
|---|---|---|
| 房間容量 | 第 9 人加入滿員房 | 拒絕、不破壞現有房 |
| 重連 | 戰中拔網 10s 再回來 | 回到相同 playerId、保留一致狀態 |
| 多重重連 | 舊 socket 又傳發炮封包 | 全數拒絕舊 epoch |
| 命中權威 | 客戶端偽造爆頭/勝場/傷害 | 被拒絕，server 不變 |
| 速度作弊 | 每秒宣稱位移 100m | 無效並被記錄 |
| 重複購買 | 同一 transactionId 連點 100 次 | 只扣 1 次 |
| 重複結算 | matchId 同一玩家結算重發 100 次 | 只加 1 次經驗貨幣 |
| 坦克碰撞 | 8 車互撞/挨牆 10min | 沒有永久卡死與瞬移 |
| 旗競搶 | 兩台車同 tick 踩中 | 只允許一個 holder |
| 高延遲 | 150ms RTT + 2% 丟包 | 比分一致、可操作、無雙重擊殺 |
| 出生 | 1,000 次隨機重生 | 沒有出界、夾物或鎖死 |
| 平局 | 時間到比分相同 | 結果一致且依規格記 DRAW |
