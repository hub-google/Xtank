# 22｜多人 LAN、EXE 試玩和目前限制（2026-10-22）

## 這版真正完成了什麼
0.2.0 是**第一版多人可對戰原型**，不是正式全國連線營運。已具備：
- 8 款可選坦克；7 個武器鍵位（1–7）；6 個道具鍵位（F1–F6）。
- 單機 AI 模式或連到房間伺服器後與其他真人對戰，最多 8 人，其餘位置由 AI 填補。
- FFA/TDM/持旗 3 模式；生命、護盾、碰撞傷害、擊殺與結算。
- 伺服器主導所有戰鬥計算；WebSocket 房間、6 碼房號、房主開局、重連 30 秒內保留位置。
- 場上煙霧和群體修復效果，地雷佈置、追蹤飛彈、基本雷達小地圖。
- Windows Portable EXE 本機開啟 LAN 伺服器（8787 埠），無需自行裝 Node；單獨用 Node 也能開無畫面專用伺服器。
- GitHub Actions 的 Node 規則測試、兩客戶端 WebSocket 整合測試、Vite/Electron Windows 打包。

## 同一個 Wi-Fi / LAN 的兩台 Windows 電腦
1. 在本 repo **Actions > Build Windows EXE** 找最新成功且對應 0.2.0 的工作流程，從 Artifacts 下載 **XTANK-Windows-Portable-EXE**，解壓縮取得 EXE。
2. 電腦 A 執行 EXE，選擇坦克與模式，按「**在本機開啟 LAN 伺服器**」。程式顯示一組或多組 ws:// 開頭的網址。
3. A 按「建立多人房間」，記下**六位數房號**。若啟動服務失敗，檢查 8787 是否被占用，以及 Windows 防火牆。
4. 電腦 B 同樣執行 EXE，將 A 畫面顯示的**內網 IPv4 網址**（例如 ws://192.168.1.15:8787，不能直接照抄此例）填進伺服器欄，再填六位房號，按「加入房間」。
5. A 在房間看到至少兩位玩家後按「房主：開始連線對戰」。每台電腦會操控各自一台坦克，其他車交給 AI。每台電腦的出場模式都以伺服器房間設定為準。
6. 若 A/B 不同 Wi-Fi，這套純 LAN 網址通常不會通；必須自行部署可從兩地存取的 WSS 主機，不能假裝 GitHub Pages 可當遊戲伺服器。

## 指令與服務端
Node.js 22+，專案根目錄：
- npm install
- npm test
- npm run build
- npm run server
可設定 PORT=8787、BIND_HOST=0.0.0.0。HTTP GET /health 可看伺服器是否運作。只有前端的 GitHub Pages 不會自動部署伺服器。

## 現階段網路安全限制
- LAN 使用**明文 ws://**，只限可信賴的家中或測試區網；公開 Internet 必須由自己的反向代理終止 TLS（wss://）並配置伺服器安全設定。
- 伺服器驗證移動方向、角度、武器所有權、彈量、連發冷卻；不信任客戶端自報傷害、HP、分數。
- 僅有房碼而**無高強度密碼與正式帳號系統**；房碼不算完整的存取控制。
- 初版有基本封包速率限制和會話代碼，但還沒有完整 anti-cheat、延遲補償、玩家檢舉或區域配對系統。
