## 4. 需要原始安裝檔／客戶端才能解決的資料
- ID U-01：原版每個版本的安裝包 hash、來源、使用合法性、可在虛擬 Win98/XP 環境離線測試與否。
- U-02：完整地圖文件與正式地圖名稱、碰撞形狀、出生點、旗池、尺寸和路線。
- U-03：完整武器／道具名稱、彈藥、模型、效果、價格、數值；接近 120 武裝配備的實際構成。
- U-04：8 車完整原始五項能力與成長公式，版本差異和技能耗血。
- U-05：搶旗模式的真實旗種、計分時間、刷新與中斷規則。
- U-06：射擊物理、爆炸自傷、撞擊互傷、同隊誤傷、回合長度、斷線續戰。
- U-07：原版 HUD、商店、五種相機的角度與距離、原音效作者和授權。
- U-08：2006 Return 的與原始版混用資訊、潛在未發行車種不能加到原版 8 種。

## 5. 查到新證據怎麼更新
1. 先把檔案連結、發表日期、來源文字最小必要摘要和版本寫入此頁。
2. 對應車種／武器／地圖加原字串與來源，避免只有翻譯名。
3. 在 20 的資料結構記 evidenceId 與 status；替換遊戲配置時建立新 rulesetVersion 而非偷偷改數值。
4. 保留舊版、附測試結果；尚未核實的收藏包與圖片不對外散布。
