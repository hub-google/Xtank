# 00｜新手入門：X-TANK 到底怎麼玩？

如果你完全沒玩過 X-TANK，先記住一句話：**這是一款最多 8 人同場、靠坦克性能差異與武器配裝取勝的 3D 即時射擊遊戲。**

## 一場遊戲之前，你要做什麼？

1. 選一台坦克。
2. 準備武器與道具。
3. 進入或建立戰場房間。
4. 依房間設定進行個人戰、團隊戰或拔旗戰。
5. 戰局結束後取得經驗與金錢。
6. 用成長與裝備調整下一場的打法。

因此它不只是「進場互射」；還帶有 RPG 式的成長與配裝循環。

## 新手先學會四件事

### 1. 會移動

- `W`：前進
- `S`：後退
- `A`：向左移動
- `D`：向右移動

### 2. 會瞄準與射擊

- 滑鼠：控制視線／瞄準方向
- 滑鼠左鍵或 `Ctrl`：發射目前武器

### 3. 會切換裝備

- `1–7`：切換武器快捷欄
- `F1–F7`：切換道具快捷欄
- 滑鼠右鍵或 `Space`：使用目前道具

### 4. 知道自己在玩哪個模式

- **Deathmatch**：自己殺出勝場，個人競賽。
- **Team Death Match**：分隊累積勝利積分。
- **Capture the Flag**：重點是取得並持有旗幟，不是單純擊毀敵人。

## 第一次選哪台坦克？

若只想先熟悉遊戲，最容易理解的是 **X-TANK**：能力較平均、沒有極端弱點，適合拿來熟悉移動、射擊與配裝。

如果你已經知道自己喜歡的風格，可以這樣挑：

| 你喜歡的玩法 | 可先看 |
|---|---|
| 平衡、好上手 | X-TANK |
| 找敵人、掌握戰況 | A-TANK |
| 高速突擊 | H-TANK |
| 貼近撞擊 | M-TANK |
| 重裝硬打 | D-TANK |
| 高機動遠距 | O-TANK |
| 極致速度 | R-TANK |
| 高輸出、連射感 | S-TANK |

> 上表是依已知特性做的「新手理解定位」，不是官方職業分類。

## 新手第一場的建議流程

1. 選 X-TANK。
2. 不要一開始只追求高階配裝，先熟悉 1–7 換武器。
3. 用 `C` 試過五種視角，找最順手的視角。
4. 先學會邊移動邊瞄準，不要站定互轟。
5. 打團隊模式時先辨識敵我顏色，再決定追擊目標。
6. 拔旗模式時記得：擊毀敵人不等於得分，旗才是勝負核心。
