- qa-a 用資料庫商店函式實際購買 mine 並以相同 key 重送，兩次返回相同訂單、只扣一次幣/發一次物品；HTTP 玩家 JWT 購買 chemical 的 RPC 返回 200。
- qa-a 透過 JWT RPC 保存一份 X-TANK 配裝，HTTP 200，`xtank.loadouts` 查到實際資料。
- 原型程式現有：單機 AI、8 車、3 地圖、3 模式、7 武器、6 道具、LAN WebSocket 房間和基礎遊戲結算。

## C. 已有測試但不能替代完整 QA
- 靜態 JS 語法檢查及 Windows Actions `npm test`、`npm run build` 是編譯與單元測試，不等於原生 EXE 的登入、商城、正式線上對戰測試。
- QA 測試帳號與三組金幣是**測試資料，不是真玩家或完整帳號服務**。
- 每次實際改動資料庫必須更新 `supabase/migrations`，程式功能驗證必須有 Windows action run ID 及實機截圖/trace/證據。
