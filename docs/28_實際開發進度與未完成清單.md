## C. 已有測試但不能替代完整 QA
- 靜態 JS 語法檢查及 Windows Actions `npm test`、`npm run build` 是編譯與單元測試，不等於原生 EXE 的登入、商城、正式線上對戰測試。
- QA 測試帳號與三組金幣是**測試資料，不是真玩家或完整帳號服務**。
- 每次實際改動資料庫必須更新 `supabase/migrations`，程式功能驗證必須有 Windows action run ID 及實機截圖/trace/證據。
