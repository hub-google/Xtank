# 21｜可玩初版實作進度／試玩

版本：0.1.0，2026-10-22。**這是遊戲功能原型，不是完整還原或完整連線服務。**
- 已實作：Three.js 程序化 3D 巨型書桌、八種坦克可選、WASD 移動、滑鼠瞄準、直射／連射／爆炸武器、護盾與生命、AI 互射、碰撞、道具、簡化技能、旗幟持有計時、個人／團隊戰、結算、迷你地圖。
- 未實作：真人線上 WSS 房間、個人帳號、商店、原版完整資源、原版精確數值、排行榜；Windows 正式 EXE 是否成功，必須以 Actions 綠燈及 artifact 為準。
- 請勿宣稱目前是多人線上遊戲。真人多人是後續 M2 階段。

## 如何取得 Windows EXE
1. 在 [GitHub Actions / Build Windows EXE](https://github.com/hub-google/Xtank/actions/workflows/windows-exe.yml) 找到最新的成功（綠色）執行。
2. 在執行紀錄底部 **Artifacts** 點 **XTANK-Windows-Portable-EXE** 下載 ZIP，解壓縮後開啟 \`XTANK-Prototype-0.1.0-Windows.exe\`。
3. 這是**未數位簽章**的 Windows 測試程式，可能被 SmartScreen 提醒；請由本專案自己的 GitHub Actions 取得，不應關閉整機防護軟體。
4. 官方遊戲美術與程式碼未被複製，遊戲玩法以自製原型呈現。

## 開發者本機
Node.js 22+，執行 \`npm install\`、\`npm test\`、\`npm run dev\`；桌面預覽 \`npm run desktop\`。Windows 打包 \`npm run build && npm run dist:win\`。GitHub Pages 可另行新增前端部署流程，但不能當多人伺服器。

## 操作
- W/A/S/D 移動，滑鼠指向要射的方向，按住左鍵射擊。
- 1/2/3 切換颶風、火神、化學爆破彈（有限彈量）。
- F1 修復生命、F2 加速、E 施展車種能力；P 暫停、Esc 回主選單。
- 可選 8 車，FFA/團隊戰/持旗戰；敵人與隊友是離線 AI。

## 已知限制
- 所有地圖採自製幾何佔位，沒有原版歷史資源或音效。
- AI 導航是簡單避障，不是完整 navmesh，可能短暫卡在桌上障礙物。
- 部分技能只有基礎啟動效果，尚未實作對應完整視覺與雷達揭露邏輯。
- 無真人連線，無持續資料庫，關閉 EXE 不會保留戰績。
- 測試數值均為設計提案 P，而非官方數據；設計參考 docs/10–20。
