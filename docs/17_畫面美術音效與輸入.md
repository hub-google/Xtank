# 17｜UI、視角、場景風格、音效與素材資產 v0.1

## 1. 復刻畫面風格
歷史特色是字母外形 A/D/H/M/O/R/S/X、迷你坦克、日常物件放大的 3D 戰場。先做可辨認輪廓，不要以擬真的現代主戰坦克取代所有車形；原版模型與貼圖未取得授權前只採自行建模資產。

## 2. 必備頁面（P）
1. 首頁：開始、快速進房、操作教學、設定。
2. 坦克機庫：8 車旋轉預覽、屬性比較、技能、基本武器、配裝欄。
3. 房間列表：模式、地圖、當前人數、密碼、延遲、狀態，建立房間／加入／重連。
4. 房間大廳：房主、隊伍、準備按鈕、坦克與地圖縮圖、聊天簡訊（初版可關閉）。
5. 戰鬥 HUD：HP、Shield、技能剩餘、武器 1–7、道具 F1–F7、彈量/冷卻、比分/剩餘時間、隊伍色、準星、擊殺公告與延遲。
6. 對戰結果：勝敗、擊殺死亡、輸出、助攻、旗分、獎勵、繼續。
7. 設定：靈敏度、畫面品質、音效、快捷鍵、色弱對比。

## 3. 控制（H1 + P）
| 歷史鍵位 | 歷史用途 | P 補充 |
|---|---|---|
| W/A/S/D | 坦克位移 | 指向相機還是車體為版本待查；第一版以相機朝向為參照 |
| 滑鼠 | 轉視線／瞄準 | Pointer Lock，Tab 臨時解除 |
| 左鍵 / Ctrl | 發炮 | 按住是否連發依武器 |
| 1–7 | 武器欄 | 顯示快捷欄 |
| F1–F7 | 道具欄 | 瀏覽器 F1 可能開說明頁，需提供可改鍵選項 |
| 右鍵 / Space | 用道具 | 阻止右鍵選單，只在玩家主動進入遊戲後 |
| C | 5 視角切換 | 五鏡頭細節為 P |
| Esc | 選單／離開 | Esc 也會釋放 Pointer Lock |

## 4. 五鏡頭（P，不是原版五鏡頭的歷史命名）
C1 第三人稱貼近：車後 5m 高 2m；C2 第三人稱中距：車後 8m 高 3.5m；C3 戰術俯角：車後 10m 高 7m；C4 低角高速：車後 6m 高 1.5m；C5 第一人稱：車身前緣高 1.2m。所有鏡頭應以射線／避障修正避免穿牆，配合不會引起暈眩的動畫。
P：鏡頭轉場 0.15–0.25s，顯示視角編號，滑鼠靈敏度不因鏡頭變更而突變。

## 5. 坦克模型與碰撞
每車需要低模原型、LOD（遠距）、輪廓色（敵我可辨）、炮口發射點、受擊特效點、炸毀特效、碰撞盒、陰影和 3 種行駛音；坦克外形可見但物理大小差異不得破壞公平性。

## 6. 音效／素材法律
列素材資產 ledger：assetId、作者/權利人、授權類型、來源 URL、驗證日期、用途、版本、hash、是否可再散布。未知來源的客戶端資料、原版音樂和截圖不得逕自重新上架；正式公開網站應使用自製／可商用授權內容並保留聲明，避免讓玩家誤認為原廠正式復活。

## 7. 品質與無障礙
- 1366×768 HUD 不遮準星，文字至少 14px（P）；紅藍隊有形狀與色彩雙重辨識。
- 60 FPS 為目標，低規設備自動關閉陰影和昂貴粒子；音量三欄可獨立調。
- 未取得原版聲音之前，使用自製提示音並明顯標示非原版。
